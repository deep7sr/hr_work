# SE Skills Playbook — UST Talent Hub

A standalone, single-file HTML engagement experience for the UST Talent Hub launch:
the **AI-Native Software Engineering Skills Playbook**.

## Files

| File | Description |
|---|---|
| `UST_SE_Skills_Playbook_v3.html` | **Current version — “field guide” edition.** A distinct editorial design language: warm paper background, serif display type, monospace spec labels, ruled lines, numbered chapters, a Fig.-A style career-lattice diagram on dotted grid paper, square proficiency markers echoing the UST logo anchor, ink-plate 5D section, scrolling ticker, and an ultramarine closing plate. Fully self-contained, no external assets. |
| `UST_SE_Skills_Playbook_v2.html` | Alternate version — dark product-page style with UST black/white brand core, electric accent spectrum, interactive career lattice and proficiency-meter explorer. |
| `UST_SE_Skills_Playbook_Final.html` | Previous version (reference). |
| `source_page_code.html`, `source_page.css` | Copies of the previous version kept for reference. |
| `SE_mail.pdf` | Requirements email thread (RSP Playbook FRD). |

## Notes

- The skills dataset (`TECH`, `LEAD`, `LEVELS` constants — 1,184 technical skill rows across 5
  specializations, 49 leadership competencies, 5-level proficiency scale) is carried over
  **verbatim** from the previous version.
- Read-only by design: no assessments, no ratings, no data capture — all validation lives in Talent Hub.
- Open the HTML file directly in any modern browser; it works offline and as an email attachment.
